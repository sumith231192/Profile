STEP 01 / 07
CV Reading & Self-Configuration
▼

Apache PDFBox grabs my CV. Groq (Llama 3.3-70B) and Google Gemini parse it into a structured profile — skills, seniority, experience, target roles. Then the agent generates fresh keywords and writes them right back into its own config file.

🧠 The agent literally rewrites its own brain before every run. No hardcoding. No manual tuning. Just AI doing what AI does best — figuring stuff out so you don't have to.

STEP 02 / 07
Multi-Country Job Hunt on LinkedIn
▼

Big shoutout to LinkedIn 🙏 Selenium fires up and searches across multiple countries simultaneously. Each city has its own isolated profile with full deduplication, so jobs never get processed twice.

🌏 Multiple cities, one nightly run. The agent doesn't sleep — but I sure do 😴. It handles the global hunt while I dream about being hired.
Selenium 4.18WebDriverManager 5.7Multi-city profilesglobalSeenJobs dedup
🧠
STEP 03 / 07
AI Match Scoring
▼

Every job gets scored against my CV using a multi-provider LLM chain — Groq AI as primary, Google Gemini 2.0 as the trusty failover, and LM Studio (Phi-4-mini / Qwen 2.5) running locally for zero-cost backup. Keys auto-rotate, providers auto-switch. Only jobs scoring ≥ 90% make the cut.

😜 Sorry Groq AI and sorry Google Gemini — I sort of found a workaround for your rate limits! Keys rotate, providers switch, and the agent just keeps humming along. No stopping. No tears.
Groq AI (primary)Gemini 2.0 (failover)LM Studio localLlmApiKeyManagerOkHttp 4.12

STEP 04 / 07
Auto-Apply or Flag for You
▼

Easy Apply available? The framework fills every field — answer files, CV data, and Groq AI for anything unknown — then hits submit. No Easy Apply? The link gets saved for manual handling. Nothing ever gets silently dropped. Every job is accounted for.

📋 Answer file → CV fields → Groq AI for the unknowns. The modal doesn't stand a chance. It's like having a very determined intern who never sleeps and never complains about paperwork.

STEP 05 / 07
Recruiter Outreach
▼

Groq AI drafts a personalized cold email per match — subject + body tailored to the specific role and company. Jakarta Mail 2.0 sends via Gmail SMTP with my CV attached. Dedup tracker keeps things polite — no recruiter ever gets the same email twice.

✉️ Personalized. Relevant. CV attached. Sent at 2 AM while I'm sleeping. A recruiter gets a thoughtful email, no idea it was crafted by an AI on a Linux container in the cloud 😄

STEP 06 / 07
WhatsApp Summary via Twilio
▼

Twilio WhatsApp API pushes a run summary straight to my phone the moment it finishes. Wake up knowing exactly what went down overnight — applied, flagged, emailed — without opening a single dashboard.

Runs Itself Daily — GitHub Actions

Scheduled GitHub Actions workflow at 01:00 UTC. Credentials in GitHub Secrets. Builds, fires, shuts down. No laptop. No trigger. No monitoring. No me. The agent just shows up and does its thing.

The Real Lesson
Takeaways
Don't fear AI. Make friends with it. 🤝

Building this completely changed how I think about automation.

"Don't use AI just to generate code.
Use it to think through the problem with you." 💭

🧠
The code is the easy bit. The architecture, edge cases, the decisions — which locations matter, what threshold makes sense, when to auto-apply versus flag — that's where you and your brain still matter.
🚀
AI doesn't replace you. It turbocharges you. I didn't use AI to write this pipeline for me. I used it as a thinking partner — to reason faster, catch edge cases earlier, and build something I couldn't have pulled off solo.
🎯
Build the system. Set the direction. Let it run. ✨ Stop thinking of yourself as "the person doing the task" and start thinking of yourself as "the person designing the system." Everything changes.
